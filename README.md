# ChemVerse

An interactive chemistry learning project designed to make exploring chemistry more engaging, accessible and enjoyable through a digital learning experience.

## Overview

ChemVerse is a chemistry-focused interactive learning project that aims to make learning and exploring chemistry more engaging. It provides a digital platform centred around chemistry and encourages users to explore the subject in an interactive environment.

## Project

- **Name:** ChemVerse
- **Live Demo:** https://chemversebyjagruti.netlify.app/
- **Domain:** Chemistry Education

## Objective

The objective of ChemVerse is to create a more engaging way of exploring chemistry by bringing chemistry-related learning into an interactive digital environment.
